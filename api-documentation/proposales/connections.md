# Integrations

> How to build a new integration towards Proposales

Press the `Contact us` button on [https://secure.proposales.com/settings/connect](https://secure.proposales.com/settings/connect) and kindly ask our customer success team to activate our connection development powerup for you.

Once activated, you will be able to register a new connection by giving it a name, logo, authentication and configure a set of endpoints that are in charge of responding to events on the Proposales platform.
